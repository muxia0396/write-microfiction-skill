## 1. 选择规则

先确定作品要解决的问题，再选择技法：

- 读者预期太直：选对比与反转类。
- 篇幅太满、解释太多：选省略与留白类。
- 需要间接批评现实：选讽刺与讽喻类。
- 需要用物象承载情绪：选象征与意象类。
- 人物只有标签：选人物显形类。
- 材料零散或节奏松：选结构组织类。
- 素材过于普通：选生活机趣类。

每篇选一种主技法，最多增加一种不同功能的辅助技法。说明技法时包含机制、适用场景、主要风险和一个原创微型示例。

本文件为了检索而按能力重新分组，下列 1–67 是**本文件的检索号，不是原书序号**。不要据此声称某技法在来源教材中的排名或次序。

识别已有文本时，先选能解释可观察结构的最具体标签，再考虑宽泛标签。辅助标签必须有独立证据和独立作用；没有精确对应技法时，宁可描述“细节增义、有限视角误导、动作留白”等功能，也不要把任何含蓄人物描写都归为“人性暗示法”。

## 2. 七个能力群

- 对比与反转：建立预期，再改变预期或评价。
- 省略与留白：控制信息，让读者参与补全。
- 讽刺与讽喻：通过错位、夸张、幽默或间接指向完成批评。
- 象征与意象：让物象、梦境、景物或氛围承载抽象意义。
- 人物显形：让人物在言行、独白、心理或考验中暴露自己。
- 结构组织：安排线索、时间、材料、蓄势和收束。
- 生活机趣：从偶然、误会、局部和关键细节中发现故事。

## 3. 67 种技法速查

### 对比、预期与转折

1. **黑白对比法**：并置性质相反的人、事、观念或状态，以反差突出主题。避免把人物简化成善恶符号。
2. **欲扬先抑法**：先制造负面印象，后用行动揭示可贵之处。前期误判必须合理。
3. **欲抑先扬法**：先建立正面印象，后显出问题、虚假或丑态。不要用无根据的新信息翻案。
4. **抑扬互易法**：让两条评价线相互转换，使先抑者后扬、先扬者后抑。适合双人物关系。
5. **欲擒故纵法**：先向表面相反的方向铺写，再转向真实意图。转向前要保留隐性牵引。
6. **巧设悬念法**：延迟回答一个具体问题，维持阅读期待。悬念必须与人物选择相关。
7. **引君入彀法**：引导读者先接受一种判断，再进入作者设置的认识转弯。必须公平提供重读证据。
8. **一波三折法**：在单线事件中设置数次有因果关系的转折。避免连续巧合。
9. **篇末逆转法**：结尾改变读者对前文的理解或评价。反转后人物动机与线索应更合理而非更混乱。
10. **强弱转化法**：让强弱、主客或权力关系发生转换。转换应来自选择、情境或信息变化。
11. **正反错位法**：让好事得坏果、坏事得好果，暴露环境或制度的反常。明确错位所指，不直接喊口号。
12. **张冠李戴法**：通过身份、对象或归属的错认形成误会与讽刺。错认需符合当时信息条件。
13. **虚张声势法**：制造夸大的声势或预期，最后显出实际结果的微小、空洞或荒诞。

### 省略、暗示与留白

14. **首尾隐现法**：省略开端、过程或结局中的一段，让读者从可见部分补全。
15. **显果藏因法**：呈现结果，隐藏原因，通过痕迹允许读者倒推。
16. **显因藏果法**：写清起因与推动力，把结局悬置给读者想象。
17. **弦外留音法**：正文收束后仍保留情绪或意义余波。结尾不解释余味。
18. **睹影知竿法**：写局部痕迹、反应或后果，使背后本体可推知。
19. **藕断丝连法**：表面中断人物、时间或事件联系，内部以细节继续相连。
20. **蛛丝马迹法**：布置细小而可回看的线索，逐步导向真相。
21. **背面入手法**：从目标对象的反面、侧面或缺席状态进入，间接显出本体。
22. **百字钩玄法**：在极短篇幅中钩出深意，依赖高密度信息和认知跳转。避免成为谜语答案。

### 讽刺、寓意与现实折射

23. **声东击西法**：表面写甲，实际指向乙，使真实批评对象间接显现。
24. **谐笑讽刺法**：以幽默、滑稽或轻松口吻完成批评。笑点必须刺中关系或机制。
25. **暗藏讽喻法**：把批评埋入人物关系和情节，不明说对应现实。
26. **借古喻今法**：借历史或旧事映照现实。避免只换古装、不建立结构对应。
27. **夸张寓义法**：把情节推到夸张或荒诞程度，以寓意指向现实。
28. **魔幻写真法**：用魔幻、鬼怪或超现实机制曲折反映真实矛盾。
29. **违反常理法**：设置反常事件，引导读者追问其社会或心理逻辑。
30. **图解影射法**：用形象化、寓言化故事呈现一个观念并影射现实。避免只剩概念图解。
31. **寓褒于贬法**：在总体应否定的人或事中发现可肯定因素，增加评价复杂性。
32. **寓贬于褒法**：在总体应肯定的人或事中显出值得警惕的因素。
33. **漫画勾勒法**：抓住突出特征作夸张速写，使人物或现象迅速显形。
34. **类型概括法**：用典型人物或场景概括一类社会现象。赋予人物至少一个非标签化细节。
35. **一箭双雕法**：让一个事件同时完成人物刻画和更大问题的呈现。
36. **包容互见法**：并置若干同类人物或片段，让它们相互印证同一种处境或社会机制。各片段必须共享核心关系，不能只是案例堆放。
37. **以喜写悲法**：以喜剧场面或轻松笔调呈现悲剧内核。
38. **以悲写喜法**：以困境和压力反衬希望、温情或生命力。
39. **以例证理法**：用具体故事承载一个认识。现代使用时删去外加结论，让事例自己成立。

### 象征、物象与氛围

40. **语义双关法**：让标题、词句或称呼同时具有表层与深层意义。两层意义都应自然。
41. **象征寄意法**：让具体物象承载抽象情感、观念或命运。
42. **以物喻人法**：借物性、用途或变化映照人物和人事。
43. **梦境折射法**：以梦境折射愿望、恐惧、荒谬或潜意识，并与现实互证。
44. **情景交融法**：让景物变化与人物情感互相影响，不把景物当装饰。
45. **氛围渲染法**：弱化显性情节，集中营造情绪、时代感或压迫感。仍要保留微小变化。
46. **奇境设置法**：设置特殊或极端处境，使人物选择和主题集中显露。

### 人物显形与心理

47. **自设陷阱法**：让人物因自己的言行、欲望或算计陷入困境，形成自食其果的因果闭环。
48. **自我画像法**：不由作者评判，让人物通过言行、习惯和选择描画自己。
49. **自白显形法**：以人物自述暴露思想和本质，可结合不可靠叙述。
50. **谈心倾诉法**：通过谈话、书信、留言或倾诉推进情感与信息。
51. **心灵剖析法**：深入人物心理动因与精神矛盾。用外部触发和身体反应避免纯说明。
52. **过关现形法**：设置一个考验关口，让人物在压力下显露本质。
53. **意念闪现法**：让感觉、回忆、想象、情绪和当下意识交错闪现，可突破时间与空间限制。必须有当下触发物或情绪引力维持可读性，不能把随机联想误当意识流。
54. **人性暗示法**：通过事件和细节暗示欲望、怯懦、善意或自欺，不直接下判断。

### 结构、线索与节奏

55. **烘云托月法**：不直接写中心对象，通过旁人、环境或反应侧面衬托。
56. **山外显山法**：先写一个已具力度的同类人物或事物，再以更强者越过它，使后者获得“山外有山”的分量。前一座“山”必须自身成立，且两者性质相通。
57. **线串珍珠法**：用一个物件、动作、话语或时间点串联多个片段。
58. **多向归一法**：让多条信息、人物反应或场景最终指向同一意义。
59. **千钧蓄势法**：连续积累压力、误解或信息，最后集中释放。
60. **时间逆行法**：以倒叙或逆向揭示重排因果，让读者先见结果再追索原因。
61. **繁复层叠法**：通过有变化的重复和层层叠加产生强化、压迫或喜剧效果。
62. **夹叙夹议法**：在叙事中穿插极简议论。现代作品慎用，议论不得替代场景。

### 偶然、误差与生活发现

63. **无意成春法**：人物无意为之的行动偶然解决矛盾或带来转机。偶然结果要由既有条件支持。
64. **大题小做法**：选择极小事件承载较大主题，以微见著。
65. **以偏概全法**：选取一个局部、片段或侧面暗示整体状况，不声称统计代表性。
66. **阴错阳差法**：由误会、错位或巧合改变情节。巧合负责制造处境，人物选择负责完成故事。
67. **颊上添毫法**：从反面添一笔似乎有损人物的动作、欲念或缺点，反而显出其更深的本色。分寸最重要：这一笔必须能被处境和整体性格重新解释，不能真的推翻人物。

## 4. 技法成立检查

选定技法后，先写出它成立所需的条件。若条件无法落到前文的动作、物件、信息或人物能力上，换技法，不靠结尾解释补救。

### 对比、抑扬与转化

- 对比的两端必须围绕同一性格、关系或问题；服装、贫富等表面差异若不改变核心认识，不算有效对比。
- 抑扬转换前后要有内在联系。前期印象来自有限视角或人物行为，后期新认识应重新解释旧信息。
- 强弱转化必须先拉开差距，再交代促成转换的主观能力或客观条件。
- 正反错位要让环境、利益或规则解释“不正常结果”，不能只靠作者安排倒霉或走运。

### 隐藏、悬念与反转

- “藏”不等于不给信息。至少留下可推断的方向、条件或痕迹。
- 悬念围绕一个合理而集中的问题展开，并在承诺回答时兑现；不要为神秘而神秘。
- 篇末逆转与解悬念不同：前者在无显眼问号的情况下改变评价，结尾后仍需读者回看推因。
- 误认必须符合人物当时掌握的信息；若一句自然对话就能澄清，人物却长期拒绝开口，误会不成立。
- 开放结尾可以不定论，但表层故事必须可读，且至少有两处证据约束解释范围。

### 间接表现、讽刺与象征

- 烘云托月中的“云”只为“月”服务，篇幅和亮度不能反客为主。
- 声东击西、借古喻今、图解影射都要建立表层故事与真实指向之间的结构对应。
- 荒诞、夸张、魔幻和反常必须扎根真实欲望或社会关系；离奇只负责放大，不能代替观察。
- 双关必须由具体语境激活两层意义；象征物既不能被作者解释完，也不能成为无解谜面。
- 讽刺应刺中欲望、利益或机制，不把对象写成无缘无故的傻子。

### 人物、心理与氛围

- 自设陷阱中的人物不是突然变笨，而是自信自己的算计；变化的客观条件使其反噬。
- 自白和自我画像要给足真假、遮掩或自欺的语言信号，让读者能形成判断。
- 心理叙事以外部刺激、感官、身体反应或反复意象为锚；意念可跳跃，情绪引力不能断。
- 奇境必须可能由文本条件生成，并迫使人物暴露平常会隐藏的部分。
- 氛围渲染即使淡化情节和人物，也要有一个点睛细节或微小变化说明这种氛围为何值得写。

### 结构、偶然与议论

- 线串珍珠的贯穿物必须实际参与各片段；多向归一的多条材料必须聚焦同一核心认识。
- 千钧蓄势把主要篇幅用于逐级累积，释放要短、准、合理，避免“雷声大、雨点小”。
- 有变化的重复才是繁复层叠；每次复现都要推进情绪、关系或意义。
- 阴错阳差中的偶然负责改变轨道，既有条件与人物选择负责完成结果。
- 夹叙夹议和以例证理仍以小说为主；议论点到为止，事例要先独立成立，道理不能简单、空泛或偏激。

## 5. 常用组合

- **可验证反转**：篇末逆转法 + 蛛丝马迹法。
- **含蓄悲情**：显果藏因法 + 弦外留音法。
- **人物翻案**：欲扬先抑法 + 自我画像法。
- **社会切片**：山外显山法 + 大题小做法。
- **轻讽刺**：谐笑讽刺法 + 正反错位法。
- **物象结尾**：线串珍珠法 + 象征寄意法。
- **心理微转**：意念闪现法 + 情景交融法。
- **考验显形**：过关现形法 + 人性暗示法。
- **开放关系**：藕断丝连法 + 模糊型主题。
- **生活巧合**：阴错阳差法 + 情趣型主题；情趣型是主题，不计入两种技法上限。

## 6. 组合禁忌与公平性检查

- 不同时堆叠篇末逆转、欲扬先抑、欲抑先扬、一波三折等多个同功能机关。
- 不用梦境宣布前文全部无效。
- 不让巧合同时制造问题并解决问题。
- 不在结尾引入此前无法推断的亲属、疾病、死亡、身份或秘密。
- 不把象征物解释给读者听。
- 不把开放结尾写成信息缺失；至少提供两个可形成解释的证据。
- 不让讽刺对象只靠愚蠢成立，应显出欲望、利益或环境机制。
- 反转后检查每个关键细节是否仍符合人物当时的认知与行为逻辑。
- 不为制造“物件变化映照人物变化”的整齐结构，让人物无合理权限地拿走、破坏或改造他人物品。
