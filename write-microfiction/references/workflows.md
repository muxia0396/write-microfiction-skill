## 1. 素材提炼与构思

把零散材料转成可叙事的“人—欲望—阻力—选择—变化”。

执行：

1. 找到最可能承受变化的人，不默认素材提供者就是主角。
2. 把抽象议题落到一个有限场景和一次具体行动。
3. 提取一个能反复出现的功能性细节。
4. 给出三种真正不同的方向，分别改变人物欲望、主题或结尾机制，而非只换标题。
5. 为每个方向标明主技法及其风险。

推荐输出：

```markdown
### 方向一：标题或一句话定位

- 核心人物：
- 当下欲望：
- 阻力/误解：
- 贯穿细节：
- 主题类型：
- 主技法：
- 五拍推进：
- 结尾机制：
- 风险：
```

## 2. 方案设计

用户要求提纲、反转或结尾时，不必写完整正文。

设计反转：

1. 先写“读者初始判断”。
2. 再写“实际真相或评价变化”。
3. 列出前文至少两个公平伏笔。
4. 说明反转如何改变人物，而非只改变事实答案。
5. 排除靠绝症、死亡、失忆、双胞胎、梦醒等廉价机关，除非题材本身需要且铺垫充分。

设计任何技法时，另写一行“成立条件”，把技法依赖的人物能力、信息差、客观条件或因果桥梁落实到前文。若只能在结尾临时补充，该设计不成立。

设计开放结尾：

1. 明确要保留哪一个判断不回答。
2. 提供支持不同解释的文本证据。
3. 让最后动作或物件完成情绪收束。

## 3. 成稿创作

### 写前

内部完成不可协商约束清单和最小创作简表，不向只要作品的用户展示推理。将每条“必须、只能、最多、不得、不要、保留”改写成可勾选的验收项。

在动笔前列出素材最容易滑向的两个惯性答案，至少放弃其中最熟悉的一个。危机救援、迟到留言、亡亲遗物、隐形富豪和突然认亲不能仅因方便收束而出现。

### 起笔

- 在前三段内出现人物、异常或行动目标。
- 从可见动作、对话、物件或正在发生的摩擦进入。
- 把背景拆散到行动需要的位置。

### 推进

- 每个场景至少改变压力、信息、关系或人物决定中的一项。
- 让关键细节出现两至三次，每次意义或情绪略有变化。
- 对话必须承担试探、遮掩、推动、误导或显形功能。
- 心理描写紧贴触发物和身体反应。
- 使用氛围渲染、意念闪现或人性暗示时，可以淡化完整情节，但必须保留一个当下锚点和一次可感知变化。
- 关键物件先服从所有权、用途、位置和人物权限。若人物必须偷拿、误毁或擅自改造物件，交代足以承担这一行为的动机与现实后果。

### 收束

- 在结尾前完成因果闭环。
- 用一个动作、细节、称呼、声音或空缺释放最终意义。
- 结尾后删除解释段，检查故事是否仍成立。

### 交付

用户没有要求分析时，只给标题和正文。不要附“使用了某某技法”“寓意是”等解说。

精确篇幅或禁词任务必须对“正文”运行严格检查；标题是否计数服从用户或平台规则。任何违规先修稿，不把检查结果展示给只要作品的用户。

## 4. 诊断与点评

先判断文体是否成立，再谈漂亮句子。

输出顺序：

1. **整体判断**：用一至两句说明目前最强之处和主要瓶颈。
2. **文本证据**：引用短语或概述具体段落，说明判断依据。
3. **优先问题**：最多列三项，按结构、细节、语言排序。
4. **修改动作**：每个问题给可执行动作，不只给形容词。
5. **示范**：仅在有帮助时重写一个关键片段，不擅自重写全文。

诊断技法时同时区分“没有使用该技法”和“试图使用但成立条件不足”。后者要指出缺的是哪一条可验证条件，不只建议“加强铺垫”。

区分症状与病因：

- “结尾没力量”可能源于前文没有建立期待或伏笔，而不是最后一句不够漂亮。
- “人物不立体”可能源于没有选择压力，而不是外貌描写太少。
- “节奏拖”可能源于场景功能重复，而不是句子普遍太长。
- “主题不清”可能源于细节互相争夺注意力，而不是缺少点题句。

## 5. 分轮改稿

先确认用户授权的改动幅度；未说明时，通常采用保守改稿并说明关键结构调整。若命中强行反转、人物没有有效选择、因果断裂或说教结尾等结构红旗，可直接升级为结构重写，但必须保留原稿的核心意图与独特细节，并在交付中说明。

### 结构轮

- 明确核心人物、欲望、阻力和变化。
- 合并同功能人物、场景和解释段。
- 检查每个转折的因果桥梁。
- 重新确定结尾要释放的意义。

### 细节轮

- 选择一个贯穿细节。
- 把抽象判断改成动作、物件、对话或身体反应。
- 为反转或留白补公平线索。
- 删除只起装饰作用的细节。

### 语言轮

- 删重复信息、套话、概念性抒情和训导句。
- 调整句长服务节奏，不追求全篇短句。
- 保留原作者有辨识度的措辞、语气和观察。
- 检查指代、时态、视角与标点一致性。

推荐交付：

```markdown
## 修改判断

说明采用轻改、结构重写或风格重写，以及最关键的两项调整。

## 修改稿

完整文本。

## 关键改动

- 结构：
- 细节：
- 语言：
```

用户只要求“直接改好”时，可省略改动说明。

## 6. 技法识别与教学

识别技法时，不因结尾意外就自动判为篇末逆转。使用“标签—证据—作用—置信度”：

```markdown
- 主技法：
- 文本证据：
- 对阅读预期/人物/主题的作用：
- 可能的辅助技法：
- 容易混淆但不采用的标签：
```

选择标签时遵循：

1. 先命名改变结构、信息分配或读者预期的最具体机制。
2. 辅助技法必须解释另一项独立功能，并有不同的文本证据。
3. “人性暗示法”“象征寄意法”等宽泛标签只在作品确实指向普遍人性或稳定象征系统时使用。
4. 若 67 种技法没有精确对应项，直接写“细节增义”“有限视角误导”“动作留白”等叙事功能，不强行套名。
5. 对每个候选标签写一句排除测试：删去该机制后，文本的哪种效果会消失？答不出来就不采用。

教学某技法时：

1. 用一句话解释机制。
2. 说明适用问题和不适用情况。
3. 给出一个 80–150 字原创示例。
4. 指出常见失败方式。
5. 给出一个可执行练习。

不要复述来源教材的受版权保护例文。

## 7. 真实资料虚构化

处理新闻、访谈、个人经历或网络帖子时：

1. 区分可验证事实、讲述者判断和未知部分。
2. 提取情境机制，不照搬真实人物身份。
3. 改变姓名、地点、职业、时间及可识别组合信息。
4. 合并或重组人物，避免影射具体私人个体。
5. 不把未经证实的指控写成事实。
6. 若作品紧贴重大真实事件，明确它是虚构创作。
7. 保留行动、冲突和感官细节，删除百科式背景。
