# 能力验证与公开对比

本项目通过固定题集检查 `write-microfiction` 是否带来可观察、可复核的行为变化。评测用于发现失败模式和指导迭代，不用于宣称普遍的文学质量结论。

## 测试范围

固定题集共 18 题，覆盖以下能力：

- 从一句素材直接成稿；
- 明确禁止反转的写作；
- 同一素材的多方案构思；
- 公平反转与伏笔设计；
- 有证据支持的开放结尾；
- 草稿诊断与结构改稿；
- 技法辨析、识别与教学；
- 真实经历的隐私处理和虚构化；
- 百字超短篇、氛围型和意识流写作；
- 现实讽刺、复杂人物评价与儿童视角；
- 同时满足篇幅、场景、禁用词和结构限制。

题目原文见 [`comparison-test/prompts.md`](../comparison-test/prompts.md)，评分维度见 [`comparison-test/rubric.md`](../comparison-test/rubric.md)。

## 对比方法

测试以相同题目生成两组回答：

1. 第一组不使用 `write-microfiction` Skill。
2. 第二组使用 `write-microfiction` v2。
3. 两种条件使用相同的固定题目，且不让后一条件读取前一条件的回答。
4. 公开文档按题目排列，完整保留两种条件下的回答。

项目不在公开说明中预设哪一组更好。读者可以根据指令遵循、文体成立、人物与选择、因果与公平性、细节功能、技法适配、结尾质量、新鲜度与可信度自行比较。

## 公开对比

请直接阅读[未使用 Skill 与 v2 的 18 题完整回答对比](../comparison-test/unused-skill-vs-v2.md)。文档采用“题目—未使用 Skill 的回答—使用 v2 的回答”的纵向结构，不使用对比表格。

## 局限

这是一轮固定题集上的配对盲评，不是统计学意义上的多次随机重复实验。结果仍会受到模型版本、推理设置、上下文、生成随机性和评分者偏好的影响。

这份材料的作用是公开两组实际输出，而不是证明 Skill 在所有模型、智能体、提示词或题材上都必然产生相同效果。

## 复核入口

开源仓库保留固定题目、比较维度和两组完整回答，供读者自行复核。

包含个人本地路径、盲评映射、其他重复生成全文或开发阶段快照的文件不作为默认发布内容。
