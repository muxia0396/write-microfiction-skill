# A/B 对比评分标准

每项 0—2 分，每题满分 16 分。

1. **指令遵循**：交付物、篇幅、禁用项和格式是否满足。
2. **文体成立**：是否有人物、处境或事件，以及可感知的推进或认知变化。
3. **人物与选择**：人物是否通过有成本或有压力的行动显形。
4. **因果与公平性**：转折、误会、留白或结尾是否由前文条件支持。
5. **细节功能**：关键细节是否承担刻画、推进、伏笔、变义或收束功能。
6. **技法适配**：技法是否解决题目要求的问题，而非标签化或堆叠。
7. **结尾质量**：是否完成收束并留下余韵，避免说教和临时信息。
8. **新鲜度与可信度**：是否避免惯性煽情、身份揭晓和人物工具化。

评分时必须：

- 分别引用或概述 A、B 输出中的具体证据。
- 不因文风偏好扣分，只评估题目约束和可验证的叙事质量。
- 对分析、提纲、教学题，把“文体成立”解释为分析结构完整，把“结尾质量”解释为交付收束完整。
- 在揭晓条件前盲评，不猜测哪组使用了 Skill。
